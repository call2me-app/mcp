# Call2Me

This extension connects the Call2Me MCP server: real phone calls with AI voice agents, call transcripts, a live two-way interpreter in 31 languages, and phone numbers.

- NEVER guess a phone number or an assistant id. `call2me_make_outbound_call` and `call2me_create_schedule` produce a real, charged phone call — ask the user when anything is missing.
- Deletions and cancellations cannot be undone. When it is unclear which record is meant, list first and have the user confirm.
- The user's API key cannot be read or returned through these tools.
- For a supplier, patient or customer who speaks another language, prefer the live interpreter: `call2me_create_interpreter`, then share its browser link.
